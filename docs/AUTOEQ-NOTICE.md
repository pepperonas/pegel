# Headphone corrections: AutoEq

`app/src/main/assets/headphones.tsv` is generated by `scripts/autoeq.py` from
[AutoEq](https://github.com/jaakkopasanen/AutoEq) at commit `7ae0f56d53074872b028649617a22bbb4232feb7`: the ten-band
result (`FixedBandEQ.txt`) AutoEq recommends for each model, 6028 models.

Measurements behind these results were made by: Auriculares Argentina, Bakkwatan, crinacle, DHRME, Fahryst, Filk, freeryder05, Harpo, Headphone.com Legacy, Hi End Portable, HypetheSonics, Innerfidelity, Jaytiss, Kazi, kr0mka, Kuulokenurkka, oratory1990, Regan Cipher, RikudouGoku, Rtings, Super Review, Ted's Squig Hoard, ToneDeafMonk.
AutoEq names its sources in its README and states no separate licence for the data.
